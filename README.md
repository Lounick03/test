# Assiette : suivi alimentaire par photo, 100 % sur l'appareil

Photographiez une assiette : un modèle d'IA qui tourne dans le navigateur repère les aliments et estime leur poids. Pas de compte, pas d'envoi de photo. L'application est dans le dossier [`docs/`](docs/).

## Lancer depuis le téléphone

1. **Activer GitHub Pages (une seule fois)** : ouvrez [les réglages Pages](https://github.com/Lounick03/test/settings/pages) dans le navigateur du téléphone (au besoin en « version ordinateur »). Sous *Build and deployment* : *Source* = **Deploy from a branch**, branche **test**, dossier **/docs**, puis **Save**.
2. **Ouvrir l'app** (1 à 2 minutes après la sauvegarde) : <https://lounick03.github.io/test/>
3. **L'installer sur l'écran d'accueil** :
   - iPhone, dans Safari : Partager, puis *Sur l'écran d'accueil*.
   - Android, dans Chrome : menu ⋮, puis *Installer l'application*.

Le premier scan télécharge le modèle de reconnaissance (de l'ordre de 100 à 200 Mo, estimation non mesurée) : faites-le en Wi-Fi. Ensuite l'app fonctionne hors ligne.

Détails, précision attendue et limites : [`docs/LISEZ-MOI.md`](docs/LISEZ-MOI.md).
